# ⚠️ Exceptions to the Rule

#### Global

- **Line Length:** 120 chars (Standard is usually 80).
- **Comments:** usage of emojis in comments to denote importance is allowed (e.g., ⚠️, ⚡).

#### Java Exceptions

- **Getters/Setters:** Do not use Lombok `@Data`. Write explicit getters/setters or use Java `Records`.

#### TypeScript Exceptions

- **Interfaces:** Interface names must NOT start with `I` (e.g., `User` not `IUser`).
